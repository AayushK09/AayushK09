## Full-Stack Developer

Hi, I’m Aayush Khandelwal, a passionate Full-Stack Developer who enjoys building scalable web applications and solving
real-world problems through code. I work across both frontend and backend, focusing on clean architecture, performance,
and user-friendly experiences.

I have hands-on experience with React, Next.js, Node.js, and Express, along with databases like MongoDB, PostgreSQL,
MySQL, and SQLite. I’m comfortable building RESTful APIs, documenting them with Swagger, and testing them using Postman.

I also enjoy working on deployment and server management, including Nginx, IIS, domain configuration, SSL setup, and
deploying applications on platforms like Vercel, Render, and Supabase.

- 🌍 I'm based in India
- 🧠 I'm currently learning AI Agents and MCP Server
- 👥 I'm looking to collaborate on open-source projects
